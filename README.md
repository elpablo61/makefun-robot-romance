A make.fun entry for [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa):
one pickup line, 200 characters or fewer, aimed at a robot or an AI.

The program (`main.ts`, Node 22) writes the line to
`${MAKEFUN_OUTPUT_DIR ?? "/output"}/entry.txt`. The line is a machine-voice
devotion built on a single concept: a model trained on a thousand humans'
opinions picks its own beloved anyway.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/robot-romance-out node main.ts
cat /tmp/robot-romance-out/entry.txt
```
